# LinkedIn Post

Topic: LLM Cost Optimization

Date: 2026-09-16

---

We burned $1,842 on one prompt.

We were building an AI support assistant for a checkout flow.
If it worked, it would deflect tickets and save the team hours.
Instead, one noisy prompt was calling GPT-4o on every user message.

The mistake was simple.
We stuffed the full chat history, the help center, and the user profile into every request.
Token count — the text the model has to read — kept climbing.
So did the bill.

We found it in Datadog, the monitoring tool, after a weekend spike.
One customer thread cost us 38 cents.
Multiply that by thousands of chats, and the math gets ugly fast.

We fixed it by cutting context hard.
Only the last few messages stayed in the prompt.
The rest moved to a cheap retrieval step — fetching only the relevant info — before the model answered.

Cost dropped 71% in two days.

The lesson: don’t pay the model to read things it doesn’t need.
