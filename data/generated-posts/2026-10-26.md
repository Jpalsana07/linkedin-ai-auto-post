The agents kept talking forever.

I was building a multi-agent workflow for a client project.
One agent reviewed code, another checked tests, and a third summarized the result.
Instead of finishing, they bounced the same task back and forth for 18 minutes.

It looked busy.
It was just stuck.

I had wired the handoff using LangChain, the agent glue layer, and gave each agent too much freedom.
No hard stop. No clear owner. No limit on retries.
So when one agent saw a weak answer, it asked the next one to rethink it, and the loop kept going.

The logs made it obvious in hindsight.
The same file path, the same question, the same “please verify” message, repeated again and again.

The fix was not smarter prompts.
It was stricter orchestration: one agent owns the step, one retry max, then a fallback to a plain deterministic check.

That was the lesson.

With multi-agent systems, coordination matters more than intelligence.
If no one is clearly responsible, the group can look productive while doing nothing.
