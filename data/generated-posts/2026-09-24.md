# LinkedIn Post

Topic: Agent Reliability

Date: 2026-09-24

---

The bot kept guessing.

I’m building an AI support agent for a B2B SaaS team.
It helps support reps answer the same customer questions faster.

This week I shipped a hard stop on vague answers.
If the agent can’t find a source, it now says so instead of improvising.

I also added a retry cap and a fallback path to Zendesk, the ticket inbox support teams use.
Before that, the agent could loop for 4 turns and still sound confident.

The metric moved, but not the way I wanted first.
Resolution rate went from 71% to 79%.
Hallucinated answers dropped from 12% to 3%.

The broken part is obvious now:
when the customer asks something slightly unusual, the agent gets shy.
It stops too early and hands the case back to a human.

That looked like a failure at first.
Then I realized reliability is not “the bot answers everything.”

Reliability is “the bot knows when to stop lying.”

That’s the lesson I’m keeping.
In agent work, a smaller honest answer is worth more than a bigger wrong one.

What do you think matters more for agents: higher autonomy or better refusal?
