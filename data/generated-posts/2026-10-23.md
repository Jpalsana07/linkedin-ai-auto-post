# LinkedIn Post

Topic: Agent Reliability

Date: 2026-10-23

---

One checkbox broke the agent.

We were building an internal support bot for a 40-person team.
It had to answer policy questions fast, because every wrong reply meant a human had to clean it up.

The bug was tiny.
A tool flag was set to “optional” instead of “required.”
That meant the agent could skip the one step that checked the source of truth.

For three days, it looked fine in demos.
Then it started answering from stale docs and one outdated Slack thread.

We caught it after 17 bad responses.
Not because the model was “smart enough.”
Because the failure was silent.

That was the real mistake:
we treated the agent like a chat app, not a system that can drift.

The lesson is simple:
if a step matters, make it impossible to skip.

What safety check have you seen save a system from looking right while being wrong?
